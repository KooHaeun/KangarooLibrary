# KangarooLibrary — 도서관 관리 프로그램

Java Swing과 MySQL(JDBC)로 만든 데스크톱 도서관 관리 프로그램입니다. *(제작 시기·수업명 입력)*

## 주요 기능

- **로그인**: 사용자·관리자 구분 로그인, 회원가입, 아이디·비밀번호 찾기
- **사용자**: 도서 검색, 대출, 희망 도서 신청, 개인 정보 확인·수정
- **관리자**: 신규 도서 등록, 회원 관리, 대출 현황 관리

## 실행

```bash
javac Klib.java
java Klib
```

MySQL에 `klib` 데이터베이스가 필요하며, DB 접속 정보는 환경변수나 설정 파일로 분리해 본인 환경에 맞게 지정합니다.

## 기술 스택

Java, Swing, MySQL(JDBC)
